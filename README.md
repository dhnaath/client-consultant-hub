# Konsultan Cerdas

Buat web app Client Operating System untuk konsultan manajemen (KBLI 70209) yang dapat digunakan lintas berbagai jenis klien. Gaya UI adalah perpaduan Notion (workspace/knowledge base minimal), TickTick (manajemen tugas yang cepat dan jelas), dan Zoho Solo (dashboard operasional konsultansi profesional). Siapkan Lovable Cloud untuk data klien, proyek, task, catatan, deliverables, dan aktivitas. Prioritaskan dashboard eksekutif, workspace klien, proyek & task dengan prioritas/status/deadline, catatan/knowledge base, serta tampilan timeline atau kalender. Gunakan bahasa Indonesia, desain modern rapi dengan nuansa profesional, responsif, dan sertakan data contoh yang relevan bagi konsultan manajemen.
